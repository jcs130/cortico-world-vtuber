# 连续语音与音色排查

同一条自然语句里的 `<动作>` 使用一次流式合成。动作按播放时间轴执行：开启逐字对齐时使用对齐结果；关闭时使用已有语速估计，收流后用真实总时长修正。估计不等于逐字精确对齐，也不启动额外模型调用。`【动作】` 的阻断语义保留。

这减少了内联表演导致的独立合成次数，并保留句内韵律连续性。固定参考音频、种子和模式仍不能保证不同文本有相同的音高、情绪或听感。不能把音色设置相同当作主观质量已通过。

排查时对齐：说话轮次与原文 → 分段请求 → 参考音频哈希、模式和种子 → 原始 PCM 哈希与采样率 → 声卡实际播放采样率。声音只做本地短窗采样；不要把音频写进 Agent 记忆或默认永久保存。

2026-10-14 的 N1 样本中，54 次请求使用同一参考、种子 42 和 ref_continuation；7 段现役 PCM 与后端哈希一致。存在内联动作将一句话切成两个独立请求的情况。连续合成的短窗对照只支持减少此类重新起声，不能证明全部句间差异已经解决。
